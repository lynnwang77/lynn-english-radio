## 第二站个人数据迁移

1. 在原来保存私人表达的设备和浏览器打开 [原 Lynn English](https://lynn-english.hshsj4dzwb.chatgpt.site/)。
2. 有桌面开发者工具时，检查并运行本仓库 `tools/export-original-lynn-english.js` 中的脚本。脚本校验原站域名，只读取该站表达本和按日保存的完成步骤，然后下载 JSON。
3. 在合并版用 **Restore** 选择 `original-lynn-english-backup.json`。确认后检查 **Lynn’s Words** 的内容。重复导入以稳定 ID 去重。原站的表达作为初稿导入，保持复习关闭。
4. 保存一份合并版 **Backup**，在另一测试浏览器恢复后核对。两个历史站点的存储按域名与设备隔离。只在手机保存过资料时，需要在该浏览器内执行导出流程。

### 普通用户的验收（建议 15–20 分钟）

1. 电脑和 iPhone 分别打开预览网址并输入密码，确认 Life / Work / Bible、Study Mode、Radio Mode、Today 和 Lynn’s Words 都可进入。
2. 在 Today 查看当天学习卡片，先不看答案自己说，再 Show English、Listen、Repeat，按实际熟练度选择 Again / Hard / Good；注意全天默认最多 5 旧 + 2 新，完成后不自动补题。用实际 15 分钟判断节奏是否合适。
3. 进入 Lynn’s Words，写入一条**测试**句子的 My First Try 和 Better English，保存、重新打开，核对两个版本；试一次「Add to review」。麦克风转写可选，用 iPhone 分别核对授权成功与拒绝授权的情况；识别文字并非发音评分。
4. 进入 Radio Mode，分别试听旧课和新课，确认循环、调速、停止；需要时检查原录音实际来自既有正式站。
5. 在正式主站**原来有收藏的同一个浏览器**点击 Backup，得到 JSON；不要删除、清空或重置旧数据。在预览站使用 Restore 导入该备份，检查旧收藏、历史进度；注意不同浏览器间的本地数据不会自动同步。
6. 预览站点击 Backup 下载一份测试备份；在另一测试浏览器使用 Restore，检查测试表达和收藏是否仍在。确认文件已安全保存后，再考虑是否在预览站迁入真实旧站私人数据。

### 原 ChatGPT Sites 第二站的私人数据导出

原站：https://lynn-english.hshsj4dzwb.chatgpt.site/

本仓库无法直接编辑原 ChatGPT Sites 项目。**最佳途径是站点拥有者在 ChatGPT 的 Sites 编辑器修改原站并经人工检查后更新原 Site 的已发布版本**（不能改变原域名，否则旧浏览器数据会不可读）。

添加页面按钮「Export My Data / 导出我的学习记录」，仅在用户点击时，从当前站点同源的 `localStorage` 读取：

- `lynn-english-words`：原始个人表达数组，保留每条记录所有字段，不修改 ID 或原文；
- `lynn-english-progress-YYYY-MM-DD`：按日期保存的每日完成步骤，保留每一日记录；
- 下载与 PR #2 的 `restoreOldSite` 兼容的 JSON：
  `{ "app":"lynn-english-site2", "version":1, "words":[...], "days":{"YYYY-MM-DD":[...]}}`。

导出操作必须是**只读、无需登录、无远程上传、无额外付费 API**。显示导出记录条数和结果。不得清空、迁移、覆盖浏览器存储。用户须在以前保存记录的**同一个浏览器/应用内浏览器**操作；Safari 与其他浏览器的原站储存通常不共用。

若暂时无法编辑 Sites 原站：继续保留原站，在该站的 Lynn’s Words 可见列表逐条安全复制所需表达到新站（小批量应急），同时等待一键导出功能；切勿使用开发者工具代码作为普通用户的唯一途径。不要声称这种手工方式能够完整迁移原来的日期和进度。

本任务在用户亲自验证真实旧收藏、私人表达及 iPhone 操作之前不可合并至 main。

### iPhone 实际验收：卡在 Listening 的修复（2026-11-21）

在 iPhone 应用内浏览器的第一次实机试用中，浏览器 `SpeechRecognition` 可能显示 `Listening...` 却没有返回任何转写，也没有清楚的麦克风授权反馈。此情况**不等于麦克风损坏**，不应宣称语音识别已在 iPhone 实测通过。

PR #2 测试分支现改为：

- iPhone/iPad 的 **Lynn’s Words** 优先显示 `🎙 用 iPhone 说英语 · 打开键盘`，点击聚焦 `My First Try`，用户随后点击 iOS **键盘上的听写麦克风**开始说话。避免使用在应用内浏览器可能卡住的网页语音识别。
- 显示明确说明：**键盘听写需要第二次点击键盘麦克风**，目前网站无法直接替用户启动系统键盘听写。语音转文字由 iOS 键盘处理；如系统听写关闭，可在 iPhone「设置 → 通用 → 键盘 → 启用听写」中启用。
- 桌面浏览器保留网页语音识别，但若 12 秒内没有结果，就停止等待并提示改用键盘语音输入（Windows: Win + H），避免一直卡在 Listening。
- `My First Try` 与 `Better English` 数据保存方式、原收藏及课程音频均未变更。

最新预览地址仍为：https://lynn-english-pr2.shipstatic.com ，密码只在私人对话中提供。验证时应先重新加载预览，再打开 `Lynn’s Words`，检查是否出现 iPhone 专用按钮，点按钮后键盘是否出现，点 iOS 键盘麦克风后是否生成可编辑文字。**尚未取得使用者完成键盘听写的实机验收结果。** 不得在此之前宣称手机听写完整验收通过或合并正式站。
