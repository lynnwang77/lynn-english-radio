# Lynn English 2.0｜统一数据与界面设计

## 数据

- 课和句沿用现有标识。旧课的 `channel`、标题、英文及音频映射继续作为兼容键；Bible、Life、Work 可通过显示分类区分。新课具有固定的课程与句子 ID。
- 课程导入沿用 version 1。可附带 `type`、`tags`、`context`、`reading` 和 `dialogue`。Life 的场景课使用 scene 类型。
- Today 保存当天分配的句子 ID。跨分类最多 5 句到期、2 句新句；有超额到期时减少新句。完成后仅标记原任务。复习间隔沿用旧逻辑。
- 个人表达单独保存。首次表达、修改版、日期、场景、说明、是否复习各自独立。加入复习后优先用修改版，尚未修改时用初稿。私人数据保留在浏览器及个人下载的备份里。
- 新备份扩展旧版格式。恢复以合并为主。第二站数据先在原域导出，再从文件导入。旧日完成记录作为历史保留。

## 界面

- 默认进入 Study 的 Today。先复习，再自主说一句；Listen、Repeat、Talk、Read 可以按需使用。
- Life、Work、Bible 是课程入口。Life 可以筛选场景和主题。Library、Inbox、Mastered 继续使用同一套课程数据。
- Radio 打开同一 Library，使用原录音、全课和单句循环、调速及 Favorites。
- Lynn’s Words 单独列出初稿和修改版。只有主动加入复习才进入 Today。跟读展示识别文字，并保留键盘输入。

## 验收

继续从现有 GitHub Pages 仓库开发。保留正式网址、原版入口和旧站，开发分支仅用于审查。核验旧收藏、旧备份、课程与音频、每日上限、旧站导入及手机和桌面的主要操作。
